If there are leftover changes, ask the user whether they want to commit them.

Use 'Resolve "<ticket title>"' as the title of the merge request/pull request.

Target branch: `develop` by default, unless the user specifies otherwise.

Add a short summary of the changes under "## Describe your changes"
Add Test plan as bullet points under "## Checklist before requesting a review" if applicable

Assign this MR/PR to me.

Give me the PR link and ask me if I want you to report to me the comments AI agent left us.
